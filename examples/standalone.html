AssetSystem — Standalone Example

Demonstrates window.AssetSystem (alias for window.GPC_ASSETS) consuming a tiny demo manifest with a custom tag vocabulary — no host project required.

Setup

<script>
  window.GPC_ASSETS_CONFIG = {
    manifestUrl: './demo-manifest.json',
    storageKeys: { uploads: 'demo_uploads', overrides: 'demo_overrides' },
    tagVocab: ['hero', 'enemy', 'tile', 'ui'],
    courses: ['World 1', 'World 2'],
  };
</script>
<script src="../src/asset-manifest.js"></script>
